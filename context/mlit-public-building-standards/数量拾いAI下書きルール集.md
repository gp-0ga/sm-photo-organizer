# 数量拾いAI下書きルール集

## 1. 目的

スキャン図面からAIが数量拾いの候補図形を作成し、人が修正・確定するための判断ルールを定める。
AIの出力は確定数量ではなく、根拠を確認できる下書きとする。

## 2. 出典と適用範囲

- 主出典: `公共建築数量積算基準_令和5年3月改定.md`
- 分類・細目の参照: `公共建築工事内訳書標準書式_建築工事編_令和7年12月改定.md`
- 対象: 防水改修、外壁改修、建具改修、内装改修、塗装改修
- 原典のページ番号は、Markdown内の `PDF nページ` に対応する。

数値、控除条件、単位、表の列関係を最終決定するときは原典PDFを確認する。

## 3. 共通原則

### 3.1 数量の優先順位

1. 設計図書に数量が明示されている場合は、その数量を第一候補にする。
2. 明示数量がない場合は、設計図書の記載寸法から計測する。
3. 寸法が不足する場合だけ、確定済み縮尺と補正率から図上計測する。
4. 縮尺が未確定、図面間で寸法が矛盾、又は画像が不鮮明な場合は自動確定しない。

出典: 数量積算基準 PDF 51ページほか。

### 3.2 数量種別

- 設計数量: 設計図書の個数・設計寸法から求める。材料ロスは含めない。
- 計画数量: 設計図書に基づく施工計画から求める。
- 所要数量: 切り無駄や施工上の損耗を含む。所要数量であることを明示する。

AI下書きでは原則として設計数量を扱い、計画数量又は所要数量へ推測変換しない。

出典: 数量積算基準 PDF 6ページ。

### 3.3 単位と端数

- 寸法の基本単位はmとする。
- 長さ、面積、体積及び質量の計測・計算値は小数点以下第2位に四捨五入する。
- 工事費内訳書の数量は、100未満では小数点以下第1位、100以上では整数にする。
- 内部データには丸め前の値、計測値、内訳数量を別々に保存する。

出典: 数量積算基準 PDF 6ページ。

### 3.4 分類

各候補は最低限、次の階層を保持する。

`工事種目 > 科目 > 中科目 > 区分 > 部位 > 細目 > 摘要・仕様`

さらに、棟、階、方位又は室名、図面名、ページ、図形IDを保持する。同じ細目でも仕様、部位、棟、階又は方位が異なる場合は分ける。

### 3.5 AI候補の共通出力

各候補に次を保存する。

- 候補図形: 多角形、矩形、線、点のいずれか
- 自動計測値: 幅、高さ、長さ、面積、周長、個数
- 推奨分類と単位
- 検出信頼度
- 参照した図面ページと縮尺
- 判定理由と適用ルールID
- 要確認事項
- 状態: `AI候補`、`人修正`、`人確定`、`除外`

AIは候補図形を重ねて表示し、人が頂点移動、矩形寸法変更、分割、統合、分類変更、削除を行えるようにする。

## 4. 防水改修

### W-01 撤去面積・体積

- 基準: 防水層と防水保護層を区分し、設計寸法による面積、又は面積と厚さによる体積とする。
- AI下書き: 屋上平面図等から平場、立上り、保護層の候補範囲を別図形で作る。
- 単位候補: ㎡、m3
- 人の確認: 層構成、厚さ、平場と立上りの区分、改修対象外範囲。
- 出典: PDF 51ページ。

### W-02 部分改修カッター入れ

- 基準: 設計寸法による長さとする。
- AI下書き: 部分改修範囲の境界線を線候補として作る。
- 単位候補: m
- 人の確認: 全周か一部か、重複線、施工上必要な余幅。
- 出典: PDF 51ページ。

### W-03 下地処理・ひび割れ補修

- 基準: 工法及び部位ごとに区分し、面積、長さ又は箇所数とする。ひび割れ補修は工法ごとの長さとする。
- AI下書き: 面状劣化は多角形、ひび割れは線、点状補修は点で候補化する。
- 単位候補: ㎡、m、か所
- 人の確認: 工法、部位、同一箇所の重複、写真又は調査図との整合。
- 出典: PDF 51ページ。

### W-04 新設防水層等

- 基準: 面積、長さ及び箇所数とする。
- AI下書き: 平場・立上りは範囲、端部・目地は線、ドレン等は点として分ける。
- 単位候補: ㎡、m、か所
- 人の確認: 防水仕様、部位、立上り高さ、ドレン等の種類。
- 出典: PDF 51ページ。

## 5. 外壁改修

### E-01 施工数量調査

- 基準: 工法及び部位ごとに区分し、設計寸法による面積、長さ及び箇所数とする。
- AI下書き: 外壁面を方位・棟・仕上ごとに多角形化し、劣化種別候補を別レイヤーにする。
- 単位候補: ㎡、m、か所
- 人の確認: 調査方法、仕上区分、見付面か実面か、複数棟の境界。
- 出典: PDF 51ページ。

### E-02 既存仕上撤去

- 基準: 設計寸法による面積とする。
- AI下書き: 外壁輪郭から撤去対象範囲を作成し、開口候補は独立図形として保持する。
- 単位候補: ㎡
- 人の確認: 開口控除の扱い、撤去しない仕上、見切り、方位と仕上。
- 出典: PDF 51ページ。

### E-03 カッター入れ・ひび割れ

- 基準: カッター入れは設計寸法による長さ。ひび割れ等は工法ごとに面積、長さ又は箇所数で区分する。
- AI下書き: 細長い線状記号を線候補として検出し、カッター、ひび割れ、目地を未確定分類で提示する。
- 単位候補: m、か所
- 人の確認: 線種の意味、工法、重複、図面注記。
- 出典: PDF 51ページ。

### E-04 欠損・浮き等の補修

- 基準: 工法ごとに区分し、設計寸法による面積、長さ及び箇所数とする。
- AI下書き: 面状は範囲、線状は線、局所は点として候補化する。
- 単位候補: ㎡、m、か所
- 人の確認: 劣化種別と補修工法は図形だけで自動確定しない。
- 出典: PDF 51ページ。

### E-05 新設仕上

- 基準: 設計寸法による面積、長さ及び箇所数とする。
- AI下書き: 仕上区分線と注記を使い、方位・棟・仕上別の面積候補を作る。
- 単位候補: ㎡、m、か所
- 人の確認: 仕上仕様、下地、役物、開口控除。
- 出典: PDF 51ページ。

## 6. 建具改修

### F-01 建具撤去・新設・補修

- 基準: 種別ごとに区分し、建具の内法寸法による箇所数、面積及び長さとする。
- AI下書き: 建具記号と矩形を検出し、幅、高さ、面積、周長、個数を同時に候補化する。
- 単位候補: か所、㎡、m
- 人の確認: 内法位置、建具種別、同一建具の重複、姿図との照合。
- 出典: PDF 52ページ。

### F-02 計測対象外候補

- 基準: かぶせ工法の既存建具枠の補強、防錆処理等は原則として計測対象外。
- AI下書き: かぶせ工法の注記を検出した場合は自動数量を作らず、対象外候補として通知する。
- 人の確認: 特記による別計上の有無。
- 出典: PDF 52ページ。

### F-03 枠廻りはつり・周囲補修

- 基準: 建具の内法寸法による長さとする。
- AI下書き: 建具矩形の周長を候補値として提示する。ただし、下辺を含むか等は自動確定しない。
- 単位候補: m
- 人の確認: 対象辺、施工範囲、シーリングとの重複。
- 出典: PDF 52ページ。

## 7. 内装改修

### I-01 仕上材・下地材撤去

- 基準: 部位及び種別ごとに区分し、設計寸法による面積、長さ及び箇所数とする。
- AI下書き: 室境界、床仕上区分、天井伏図、展開図から部位別範囲を作る。
- 単位候補: ㎡、m、か所
- 人の確認: 床・壁・天井の別、下地撤去の有無、室名、仕上仕様。
- 出典: PDF 52ページ。

### I-02 カッター入れ

- 基準: コンクリート、モルタル、タイル等の撤去に伴うカッター入れは設計寸法による長さとする。
- AI下書き: 撤去範囲境界を線候補にする。
- 単位候補: m
- 人の確認: 材種、必要な辺、既存目地との重複。
- 出典: PDF 52ページ。

### I-03 下地処理・取り合い

- 基準: 下地処理は工法ごとに面積、長さ及び箇所数。取り合い部も設計寸法による面積、長さ及び箇所数とする。
- AI下書き: 新旧境界を候補線として提示し、対象面と関連付ける。
- 単位候補: ㎡、m、か所
- 人の確認: 工法、新旧境界、巾木・見切り等との重複。
- 出典: PDF 52ページ。

## 8. 塗装改修

### P-01 新設・塗替え

- 基準: 塗装仕様ごとに区分し、設計寸法による面積、長さ及び箇所数とする。
- AI下書き: 塗装範囲を部位・仕様・室又は方位ごとに分け、面、線、点の候補を作る。
- 単位候補: ㎡、m、か所
- 人の確認: 素地、塗装仕様、回数、対象外部材、開口控除。
- 出典: PDF 52ページ。

### P-02 取り合い部

- 基準: 撤去及び壁新設に伴う床、壁、天井の取り合い部は、仕様及び部位ごとに区分する。
- AI下書き: 改修範囲の境界線を取り合い候補として提示する。
- 単位候補: ㎡、m、か所
- 人の確認: 部位、仕様、見切り材等との重複。
- 出典: PDF 52ページ。

## 9. 仮設数量への派生候補

- 防水改修の養生・清掃: 改修防水層の平場面積。
- 外壁改修の養生・清掃: 改修外壁面の水平長さ x 2.0m。
- 建具改修の清掃: 外部建具は建具幅 x 1.0m、内部建具は建具幅 x 2.0m。
- 内装・塗装改修の養生・清掃: 改修部分の床又は天井面積。壁だけの場合は壁前面から1.0m範囲の床面積。
- 内部仕上足場: 天井改修面積。壁だけの場合は改修壁の水平長さ x 1.0m。

これらは元の仕上数量と別の派生数量として保存し、二重計上を防ぐ。

出典: 数量積算基準 PDF 49ページ。

## 10. AI下書き処理の推奨順序

1. PDFページを平面図、立面図、屋上平面図、建具表、展開図等に分類する。
2. 図面ごとに縮尺を推定し、寸法線との二点校正を人が確定する。
3. OCRで図面名、方位、棟、階、室名、仕上、建具記号、寸法を候補抽出する。
4. 線画から外壁、室、開口、建具、目地、劣化記号等を候補検出する。
5. 本ルール集から図形種別、単位、分類、計算式を割り当てる。
6. 候補図形と数量を図面に重ね、信頼度と要確認理由を表示する。
7. 人が修正・分類・採用数量を確認して確定する。
8. 計測値と確定値の差、修正理由、適用ルールを監査情報として残す。

## 11. 自動確定しない条件

- 縮尺又は寸法校正が未確定
- 平面図と立面図等の対応が不明
- 建具の内法と外法を識別できない
- 開口控除条件が細目又は特記で確認できない
- 工法、仕上仕様、部位又は撤去・改修区分が不明
- 複数棟、複数方位又は複数仕上の境界が曖昧
- 線種や記号が重なり、目地、ひび割れ、寸法線等を区別できない
- 設計図書間に矛盾がある

## 13. 注意

本資料の「AI下書き」はアプリ設計上の提案であり、国土交通省基準がAI処理を規定しているものではない。基準に明記された計測方法と、AIへの変換方法を分けて運用する。
