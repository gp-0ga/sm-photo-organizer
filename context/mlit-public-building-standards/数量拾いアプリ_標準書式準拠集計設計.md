# 数量拾いアプリ 標準書式準拠集計設計

作成日: 2026-09-14  
参照: 公共建築工事内訳書標準書式（建築工事編）（令和7年12月10日改定）

## 1. 目的

図面上で拾った数量を、独自分類だけで保存せず、公共建築工事内訳書標準書式に近い階層で分類・集計する。Excel出力後の内訳書への転記を容易にし、各数量から図面ページと計測図形へ戻れるようにする。

## 2. 標準書式に合わせる階層

1. 工事種目: 建築工事、建築改修工事など
2. 科目: 庁舎、屋外施設などの工事対象
3. 中科目: 防水改修、外壁改修、建具改修、内装改修、塗装改修
4. 区分: 撤去、改修
5. 細目: 防水層撤去、壁タイル張り、AW、ビニル床シート張りなど
6. 摘要・仕様: 部位、工法、種別、寸法、下地、建具番号など
7. 数量・単位: m、㎡、m3、か所、枚、式など

注: 標準書式の帳票上では「科目」「中科目」の見え方が案件構成によって変わる。アプリ内部では名称だけで結合せず、固定IDと表示順を持つ。

## 3. 初期対象の5分類

### 3.1 防水改修

- 撤去: 防水保護コンクリート、防水立上り部保護、防水層、シーリング、手すり、笠木、ルーフドレン、とい
- 改修: 既存下地補修、アスファルト防水、ルーフィングシート防水、塗膜防水、伸縮目地、成形緩衝材、防水入隅処理、シーリング、防水立上り部保護、防水層押え金物、保護コンクリート、ルーフドレン、手すり、笠木、とい
- 主な拾い方: 面積、線、個数
- 主な単位: ㎡、m、m3、か所
- 標準書式該当: PDF 68～70ページ

### 3.2 外壁改修

- 撤去: 壁タイル、壁モルタル、役物モルタル、既存塗膜、カッター入れ、シーリング
- 改修: 施工数量調査、外壁清掃、ひび割れ部、欠損部、浮き部、下地調整、仕上塗材、壁タイル、壁モルタル、役物モルタル、シーリング
- 主な拾い方: 面積、線、個数
- 主な単位: ㎡、m、か所
- 標準書式該当: PDF 71～72ページ

### 3.3 建具改修

- 撤去: アルミニウム製、樹脂製、鋼製、鋼製軽量、ステンレス製、木製、シャッター、オーバーヘッドドア、カッター入れ、シーリング、ガラス
- 改修: AW、AG、AD、PW、PD、SD、SG、LD、SSD、SSW、WD、自動ドア、シャッター、オーバーヘッドドア等
- 主な拾い方: 矩形、個数、線
- 主な単位: か所、㎡、m、式
- 必須属性候補: 建具番号、幅、高さ、仕様、表面処理、工法
- 標準書式該当: PDF 73ページ以降

### 3.4 内装改修

- 撤去: 床・幅木・壁・天井・下地・間仕切り・点検口・ブラインドボックス等
- 改修: 床、幅木・壁、天井、その他に再区分
- 床: ビニル床タイル、ビニル床シート、タイルカーペット、カーペット、塗床、フローリング、畳、床タイル、床モルタル等
- 壁: ビニル幅木、壁下地、壁タイル、壁モルタル、軽量鉄骨壁下地、ボード、壁紙等
- 天井: 各種ボード、軽量鉄骨天井下地、廻り縁、点検口等
- 主な拾い方: 面積、線、個数
- 主な単位: ㎡、m、枚、か所、m3
- 必須属性候補: 棟、階、室名、部位、仕上げ、下地
- 標準書式該当: PDF 78～82ページ

### 3.5 塗装改修

- 区分: 改修のみ
- 部位区分: 外部塗装、内部塗装
- 細目候補: FE、SOP、EP、EP-G、DP、NAD、CL、UC、OS等
- 摘要: 種別、下地区分、部位、下地調整種別、既存塗膜除去の有無
- 主な拾い方: 面積、線
- 主な単位: ㎡、m
- 標準書式該当: PDF 83～84ページ

## 4. 1件の拾いデータに保持する項目

| 区分 | 項目 |
|---|---|
| 分類 | 工事種目ID、科目ID、中科目ID、撤去・改修区分ID、細目ID |
| 表示 | 各階層の表示名、並び順 |
| 摘要 | 部位、材料・工法・種別、寸法、下地、自由記入 |
| 場所 | 棟、階、室名、方位、立面名 |
| 数量 | 計測種別、縦、横、面積、長さ、周長、個数、採用数量、単位 |
| 根拠 | PDF名、図面ページ、図面種別、計測図形ID、縮尺、補正率 |
| 状態 | AI候補、人確認済み、手修正済み、除外 |
| 監査 | 作成日時、更新日時、修正前数量、修正理由 |

## 5. 入力画面の推奨順序

1. 工事種目と科目は案件設定から初期値を入れる。
2. ユーザーが5分類から中科目を選ぶ。
3. 撤去／改修を選ぶ。塗装改修は改修に固定する。
4. 中科目に応じた細目候補と単位を表示する。
5. 図面上で面積、線、矩形、個数を計測する。
6. 摘要と場所情報を確認して確定する。
7. 確定済み一覧で分類、摘要、採用数量を修正できるようにする。

頻繁に使う細目はプリセット化するが、標準書式にない案件固有細目も直接入力できるようにする。

## 6. Excel出力

### シート1: 数量集計

標準の並び順で、工事種目、科目、中科目、撤去／改修、細目、摘要、数量、単位の順にグループ集計する。同一細目でも棟、階、方位、室、仕様が異なる場合は別行にする。

### シート2: 拾い根拠

集計行ID、元データID、PDF名、ページ、図面種別、棟、階、方位・室名、計測値、採用数量、縮尺、補正率、備考を出力する。

集計数量から根拠行をたどれ、根拠行からアプリ上の図形を再選択できるIDを保持する。

## 7. 集計ルール

- 数量は内部では丸め前の値を保持する。
- 計測・計算数量は四捨五入して小数点以下第2位とする。
- 工事費内訳書の数量は、100未満では小数点以下第1位、100以上では整数とする。
- 標準書式別集計には「計測数量」と「内訳数量」を併記し、元の未丸め値も内部に保持する。
- 手修正時も自動計測値を消さず、「計測値」と「採用数量」を分ける。
- 開口控除は、控除前面積、開口面積、控除後面積、開口率を保持する。
- 建具は面積と周長と個数を同時に保持し、細目に応じて採用単位を選ぶ。
- 標準書式で `1式` とされる項目も、根拠側には実測明細を保持する。

## 10. 原典照合上の注意

Markdownでは表の列位置が崩れる箇所がある。細目名、摘要、単位の最終マスター化では、該当PDFページの表を目視照合して確定する。
