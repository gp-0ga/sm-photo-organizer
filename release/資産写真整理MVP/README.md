# 資産写真整理 MVP

健全度判定表の `No11` シートから資産と点検項目を読み取り、調査写真用のフォルダと資産切替QRを作成するローカルWebアプリです。

## 現在の範囲

### 段階1・iPhone撮影テスト

- `No11`から読み込んだ資産を手動選択
- Webカメラで撮影し、選択中の資産へ振り分け
- 別資産へ切り替えた後、元の資産へ戻って追加撮影
- 1.0〜5.0倍のデジタルズーム
- 長辺最大2,560px、JPEG品質80%で試験保存
- 資産ごとの撮影枚数を画面表示

**現段階の撮影データはブラウザ内の一時保持です。再読み込み・画面終了で消えるため、操作・画質テストにだけ使用してください。**

### PC写真整理・写真帳

- `資産番号_資産名称` フォルダを作成
- 各資産内に `全景` と `項目番号_点検項目` サブフォルダを作成
- 点検項目 `経過年数` は除外
- 資産切替用QR一覧を生成・印刷
- QRマーカーを含む撮影写真を資産別に自動分類
- 未分類・要確認写真をPCで一括修正
- 全写真を200KB以下のJPEGとして資産直下へ出力
- 写真帳採用写真を `全景` または点検項目サブフォルダへコピー
- 写真帳様式のコピー内へ、健全度判定表の最新 `No11` を反映
- 全景1枚・確認項目ごとに最大4枚を所定枠へ貼り付け
- 写真のない確認項目の写真行を折りたたみ、`経過年数`の表示行を削除
- 元のExcelは変更しない

## 起動方法（会社PCでの試用）

1. `release` 内の `資産写真整理MVP` フォルダ一式をPC内の作業用フォルダへコピーします。
2. `start-mvp.bat` をダブルクリックします。
3. ブラウザが開いたら、健全度判定表、写真、写真帳様式の順に選択します。
4. 終了時は、起動時に表示された黒い画面を閉じます。

処理はPC内で行い、選択したExcelや写真を外部へ送信しません。Microsoft EdgeまたはGoogle Chromeを使用してください。写真帳作成にはMicrosoft Excelが必要ですが、その他の追加ソフトは不要です。
