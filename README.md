# 資産写真整理 MVP

点検対象の資産一覧表（Excel）から資産と点検項目を読み取り、調査写真用のフォルダと資産切替QRを作成するローカルWebアプリです。

## 現在の範囲

### 段階1・標準カメラ撮影

- 資産一覧表から資産切替QRを作成
- QRカードを別のiPhone・iPadへ大きく表示、または全件印刷
- iPhone標準カメラでQRカードを1枚撮影して資産の開始位置を記録
- 写真はiPhoneの写真アプリへ通常どおり保存
- 別資産へ切り替えるときや以前の資産へ戻るときは、その資産のQRカードを再度撮影

### PC写真整理・写真帳

- `資産番号_資産名称` フォルダを作成
- 各資産内に `全景` と `項目番号_点検項目` サブフォルダを作成
- 点検項目 `経過年数` は除外
- 資産切替用QR一覧を生成・印刷
- QRマーカーを含む撮影写真を資産別に自動分類
- 未分類・要確認写真をPCで一括修正
- 全写真を指定容量（50～5000KB）以下のJPEGとして資産直下へ出力
- 写真帳採用写真を `全景` または点検項目サブフォルダへコピー
- 写真帳様式のコピー内へ、資産一覧表の最新内容を反映
- 全景1枚・確認項目ごとに最大4枚を所定枠へ貼り付け
- 写真のない確認項目の写真行を折りたたみ、`経過年数`の表示行を削除
- 元のExcelと元写真は変更しない

## 起動方法（PCでの試用）

1. `release` 内の `資産写真整理MVP` フォルダ一式をPC内の作業用フォルダへコピーします。
2. `start-mvp.bat` をダブルクリックします。
3. ブラウザが開いたら、資産一覧表、写真、写真帳様式の順に選択します。
4. 終了時は、起動時に表示された黒い画面を閉じます。

処理はPC内で行い、選択したExcelや写真を外部へ送信しません。Microsoft EdgeまたはGoogle Chromeを使用してください。写真帳作成にはMicrosoft Excelが必要ですが、その他の追加ソフトは不要です。
